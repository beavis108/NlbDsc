TOPIC
    about_NlbDsc

SHORT DESCRIPTION
    DSC resources to deploy and configure Windows Network Load Balancing (NLB) clusters.

LONG DESCRIPTION
    This module contains DSC resources to create an NLB cluster, to configure
    the port rules of the cluster and to add additional nodes to the cluster.
    The resources install the required Windows features (NLB and RSAT-NLB)
    when they are missing.

EXAMPLES
    See the examples in the Examples folder.
